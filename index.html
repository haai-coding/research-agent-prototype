核心功能

强大的研究助手，帮助您自动化信息收集、分析与报告生成

🔍

智能搜索

自动执行多源信息检索，从学术论文、技术文档到新闻资讯，全面收集相关数据。

🧠

深度分析

利用 LLM 进行语义理解、关键信息提取和观点归纳，快速把握研究要点。

📊

报告生成

自动生成结构化的研究报告，包括摘要、方法论、发现和结论，支持多种输出格式。

🔄

迭代优化

支持多轮研究迭代，根据反馈调整搜索策略和分析深度，持续改进报告质量。

🔗

知识图谱

构建实体关系网络，可视化研究领域的关键概念和它们之间的联系。

⚡

高效执行

并行处理多个研究任务，智能调度资源，大幅缩短研究周期。

快速开始

只需几行代码，即可启动您的研究助手 

# 克隆仓库
git clone https://github.com/haai-coding/research-agent-prototype.git
cd research-agent-prototype

# 安装依赖
pip install -r requirements.txt

# 配置环境变量
export OPENAI_API_KEY="your-api-key"

# 启动服务
python main.py --config config.yaml
